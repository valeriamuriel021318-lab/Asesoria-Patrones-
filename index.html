Checklist de comprobación

1. Contradicciones en declaraciones: Si dos personas se contradicen (una dice V y otra F), la única verdad o mentira del grupo está en ese par.
2. Contrarrecíproca limpia: Para "Si P, entonces Q", equivale únicamente a "Si no Q, entonces no P". Invertir y negar.
3. Descarte de cuantificadores: Desmentir "Todos son P" requiere hallar tan solo un caso de "Al menos uno no es P".

Reglas de oro aplicadas

• Condicional Falso: Solo se rompe con V → F (se cumple la condición y no la consecuencia).
• Leyes de De Morgan: Al negar (P y Q), se obtiene (No P o No Q). La "y" cambia a "o".
• Sin chisme: Solo se concluye lo que está explícitamente garantizado en el enunciado.

Concepto 1

1. Tipos de sucesiones en la UdeA

PA

Progresión Aritmética

Suma o resta constante (d) entre términos consecutivos.

Término general:
an = d · n + c
Ejemplo: 2, 5, 8, 11… (d=3) → 3n − 1
Suma de n términos:
Sn = (a1 + an) · n / 2
PG

Progresión Geométrica

Multiplicación por una razón constante (r).

Término general:
an = a1 · rn-1
Ejemplo: 3, 6, 12, 24… (r=2) → 3 · 2n-1
Típico UdeA: Crecimiento bacteriano, cultivos y duplicación.
Rec

Recurrencia

Cada término depende de los anteriores.

Secuencia Fibonacci:
1, 1, 2, 3, 5, 8, 13, 21…
Fn = Fn-1 + Fn-2
Preguntas clave: Posiciones de números pares, genealogía de abejas.

Concepto 2

2. Sucesiones cíclicas y el poder del residuo

Cuando un patrón se repite cada T elementos (periodo), el residuo de la división nos da la respuesta exacta.

Algoritmo del Residuo en 3 Pasos

Paso 1: Identifica la longitud del periodo T (cuántos elementos tardan en repetirse).
Paso 2: Divide la posición deseada N entre el periodo T: N ÷ T.
Paso 3: Evalúa el residuo R:
• Residuo 1, 2, 3... → ocupa esa posición dentro del bloque.
• Residuo 0 → ocupa la última posición del bloque (T).

Ejemplo Práctico

Jeroglífico con patrón: ↑, →, ↓, ← (periodo T = 4).

¿Qué flecha estará en la posición 1810?

Operación:
1810 ÷ 4 = 452 con residuo 2.

Interpretación:
Residuo 2 → 2.ª posición del bloque → →

Teoría 2

Regla de oro: Residuo 0 siempre corresponde a la última posición del ciclo.
Concepto 3

3. Tres estrategias maestras Razona UdeA

E1

Empaquetar

Agrupa el ciclo en bloques de suma conocida.

Si la suma de un bloque de 6 números da 0, multiplica los bloques completos por 0 y suma únicamente los términos sobrantes.
E2

Particularizar

Estrategia inductiva de casos pequeños.

Prueba para n = 1, n = 2 y n = 3. Encuentra el patrón de crecimiento y extrapola con seguridad al término n = 100.
E3

Análisis Telescópico

Números figurados y acumulaciones.

Para secuencias triangulares (1, 3, 6, 10, 15…) o cuadradas (1, 4, 9, 16…), utiliza la fórmula del acumulado: n(n + 1) / 2.
Método M.A.E.: Con estas 3 herramientas resolveremos cualquier patrón sin realizar cuentas infinitas.
